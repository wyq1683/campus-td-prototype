导出 / 应用

1. 点「导出 config.json」下载编辑后的数值（单一数据源）。
2. 覆盖 campus_td/build/m10_config.json。
3. 运行 python build/m10c_webcfg.py 把数值推回 web/config.js。
4. 刷新 web/index.html 即可用新平衡试玩（带 ?selftest=1 自检）。
5. 若需同步进 Blender 的塔防层（M7/M10），重跑对应脚本（它们读 m10_config.json）。
